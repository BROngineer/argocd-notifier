argocd-notifier is installed.

1. Check the status:
   kubectl get pods -n {{ .Release.Namespace }} -l app.kubernetes.io/instance={{ .Release.Name }}

2. Connect it to the ArgoCD notifications-engine. Read:
   https://github.com/BROngineer/argocd-notifier/blob/main/docs/setup.md
{{- if .Values.leaderElection.enabled }}

3. Leader election is on. Every pod must be Ready.
   A non-leader forwards requests to the leader. It does not fail readiness.
   See docs/design.md#high-availability.
   Check that exactly one pod holds the lease:
   kubectl get lease {{ .Values.leaderElection.leaseName }} -n {{ include "argocd-notifier.leaderElectionNamespace" . }} \
     -o jsonpath='{.spec.holderIdentity}{"\n"}'
{{- end }}
